Install from the project directory:

  uv sync --extra dev --extra png

Generate and verify examples:

  uv run python scripts/build_schematic.py --png
  uv run python scripts/verify_schematic.py --png
  uv run python scripts/build_schematic.py --diagram mzi --png
  uv run python scripts/verify_schematic.py --diagram mzi --png
  uv run python -m pytest
  uv build

SVG requires only the core Python package. PNG needs the optional CairoSVG
dependency and native Cairo. See README.md for macOS loader configuration.

Generated files go to build/examples/ by default. --output-dir chooses another
directory; --width sets PNG width (default 7200). PNGs embed attribution and
600 dpi resolution. The Node render/verification scripts are compatibility
wrappers around these Python tools and need no Node rendering dependencies.

The original top-level SVG, PNG, ZIP and components/ records are retained as
the reference figure and source archive. They are not overwritten by builds.

src/beampath/examples.py describes both diagrams with the public DSL.
Component definitions, graph editing, spacing, and rendering are separate
modules. See README.md for branches, joins, shared optic refs, reusable chains,
layout hints, and registering components with any number of named ports.
